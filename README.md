# 金南俊的旧手机

解锁密码：0613。把 dist 作为静态网站根目录打开（例如在 dist 里运行 `python3 -m http.server 8000`）。

这是 BTS 同人虚构作品。聊天、短信、电话、备忘录及日期安排并非真实私人记录。

## 外观
白色 iPhone 5 · iOS 6 风格：滑动来解锁、四格密码、玻璃 Dock、条纹设置页、皮革备忘录、黑色标签栏。
电脑上点机身下方的 Home 键回主屏幕；手机上用屏幕里可拖动的小白点（AssistiveTouch）。
图标、壁纸均为本作品原创绘制，不是苹果官方素材。

## 内容编辑
- data/people.js：机主与联系人
- data/chats.js：成员、妈妈、方PD、经纪人及宿舍群聊
- data/channels.js：聊天软件里的两个广告频道（虚构店铺）
- data/phone.js：短信、电话、日历、闹钟
- data/phone-more.js：备忘录、地图、Safari、天气
- data/reader-extras.js：问名字、打招呼、转账与礼物的回复
- data/assets.js：头像、照片、文件与音频槽位

原框架署名：made by 霹雳小猫。
